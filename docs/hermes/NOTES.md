# PTS — Notes (rolling)

Purpose: durable, chronological notes so we never rely on chat memory for context.

How to use:
- Append new entries at the top (newest first).
- Keep entries short: decision, context, links, next action.
- If an entry becomes a decision, move/duplicate it into `docs/DECISIONS.md`.
